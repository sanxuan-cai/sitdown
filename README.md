# 坐站助手 1.1.0

原生 macOS 状态栏应用，支持 macOS 13 及以上。使用 SwiftUI、AppKit 和 ServiceManagement，无第三方依赖。

## 使用

打开 `dist/坐站助手.app`。首次打开显示设置窗口，以后从顶部状态栏进入。关闭窗口不会退出；请在状态栏菜单中选择「退出坐站助手」。

- 坐姿默认 30 分钟、站姿默认 15 分钟，可分别设置 1～240 分钟；延后默认 5 分钟，可设置 1～60 分钟。
- 到期弹出置顶窗口，只有确认才切换姿势；支持提前确认、延后、结束。未确认和延后期间继续累计当前姿势。
- 提示音默认关闭，开启后到期等待期间每 30 秒播放。
- 自动调度默认关闭，预设 09:30～12:00、14:00～18:00，最多 12 个时段。可限制工作日，不处理法定节假日和调休。不允许重叠或跨午夜。
- 时段内启动应用会从坐姿开始，时段结束自动停止。手动结束的自动时段不会再启动；手动启动的会话需手动结束。
- 今日统计按确认姿势累计，按午夜分日。停止、睡眠、用户会话暂离和应用未运行时不累计。无历史查询或导出界面。
- 保存设置、截止时间、姿势和统计，重启恢复；超时后显示提醒。统计约每 15 秒保存，切换、结束、正常退出时立即保存。
- 可在提醒设置中开启登录启动；系统要求审批时可跳转到系统登录项。

数据位置：`~/Library/Application Support/SitStandAssistant/state.json`。统计在本机保存，无账号和网络请求。

## 开发与打包

使用 Xcode 15+ / Swift 5.9+，通过 Swift Package 打开本项目即可编辑。`scripts/build-app.sh` 生成当前 Mac 架构的 Release app 并使用本机临时签名；`swift test` 运行计时和统计回归测试。

本机产物没有 Apple Developer ID 公证。向其他 Mac 公开分发之前，需要正式签名、公证并分别构建所需架构。跨桌面和全屏提醒使用 macOS 浮动辅助面板；应用退出、电脑关机或睡眠时无法提醒。
